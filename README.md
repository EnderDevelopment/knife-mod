# Knife Mod

Adds a variety of knives to Minecraft with custom damage and durability.

## Features

- Adds multiple knives with different materials (wooden, stone, iron, diamond, netherite, copper, and Twixxel's knife)
- Each knife has custom damage and durability values

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod from the releases page.
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

- Craft or obtain the knives in-game.
- Use the knives to deal damage to enemies.

## Configuration

The mod does not have any configuration files. All settings are hardcoded in the mod.
